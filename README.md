# SSIT 면접 연습 (모바일 웹앱 / PWA)

`interview-qa.md`의 질문·답변 **59문항(9개 장)** 으로 면접을 연습하는 정적 웹앱입니다.
백엔드·로그인 없이 동작하고, 연습 진도와 타이머 설정은 브라우저(localStorage)에 저장됩니다.

## 로컬 실행

### 방법 1: 로컬 서버 (권장, 오프라인/PWA 동작)
```bash
npx --yes serve .
```
터미널에 표시되는 주소(기본 `http://localhost:3000`)를 브라우저로 엽니다.

### 방법 2: 파일 바로 열기
`index.html`을 더블클릭해 브라우저로 엽니다.
모든 기능이 동작하지만, `file://`에서는 서비스 워커가 등록되지 않아 오프라인 캐시와 홈 화면 설치는 안 됩니다.

## 휴대폰(갤럭시 S25+)에서 쓰기
1. PC와 휴대폰을 같은 와이파이에 연결하고 `npx --yes serve .` 실행
2. 휴대폰 Chrome/삼성 인터넷에서 `http://<PC의 IP>:3000` 접속
3. 메뉴 → **홈 화면에 추가**

> 참고: 홈 화면 설치와 오프라인 캐시(서비스 워커)는 `localhost` 또는 **HTTPS** 에서만 동작합니다.
> 같은 와이파이에서 `http://IP` 로 접속하면 사용은 되지만 설치는 안 될 수 있습니다.
> 제대로 설치하려면 GitHub Pages, Netlify 같은 HTTPS 정적 호스팅에 이 폴더를 올리세요.
> 한 번 열어 두면 이후에는 비행기 모드에서도 열립니다.

## 기능
- **홈**: 1~9장 목록, 장별 문항 수, 연습 진도, 전체 진도, **전체 섞기**, 진도 초기화
- **연습 화면**: 질문만 먼저 보이고 **모범답안 보기/숨기기** 토글로 답을 엽니다
- **본인 확인 뱃지**: `[본인 확인]` 문항은 노란 뱃지가 붙고, 답을 열면 초안 답변(메모)이 보입니다
- **타이머**: 시작/일시정지/리셋, 경과 시간 mm:ss, 목표 60/90/120초(기본 90초).
  목표 시간에 도달하면 빨갛게 바뀌고 한 번 진동하지만 답은 자동으로 열리지 않습니다
- 이전/다음, 진행 `n/N`, **연습함 표시**(문항마다 켜고 끌 수 있음)
- **발표 자료(PPT 모드)**: 홈의 「발표 자료」에서 `ppt-slides.md` 3장을 원문 그대로 슬라이드로 보며(스와이프·이전/다음·페이지 도트) 전체 3분 타이머(장당 권장 1분, 자동 넘김 없음)로 연습합니다. md 수정 후 `python3 tools/build-slides.py`
- **입학지원서**: 홈의 「입학지원서」 또는 발표 화면 상단 「🎤 입학지원서」 탭에서 `ppt-answers.md` 1·2·3번 답변 전문을 원문 그대로 장별로 넘기며 봅니다(장 제목 유지, 「📊 슬라이드」 탭으로 같은 장 슬라이드 복귀). md 수정 후 `python3 tools/build-answers.py`
- **입학지원서 = 읽기용**: 답변 보기에는 타이머가 없습니다(답변 탭으로 가면 3분 타이머는 일시정지·숨김, 「📊 슬라이드」 탭으로 돌아오면 다시 표시).

## 질문을 수정했을 때
`interview-qa.md`를 고친 뒤 데이터 파일을 다시 생성합니다.
```bash
python3 tools/build-data.py
```
`js/data.js`가 갱신됩니다(JSON 임베드). 서비스 워커는 네트워크를 먼저 쓰므로 온라인 상태에서 새로고침하면 반영되며,
앱 파일 구조를 바꿨다면 `sw.js`의 `CACHE` 버전을 올려 주세요.

## 파일 구성
```
index.html             화면
css/style.css          스타일 (다크 모드 지원)
js/data.js             질문·답변 데이터 (자동 생성)
js/slides-data.js      발표 자료 데이터 (자동 생성)
js/answers-data.js     입학지원서 데이터 (자동 생성)
js/slides.js           발표(PPT) 모드
js/app.js              앱 로직
sw.js                  서비스 워커 (오프라인)
manifest.webmanifest   PWA 매니페스트
icons/                 앱 아이콘
tools/build-data.py    md → data.js 변환
tools/build-slides.py  ppt-slides.md → slides-data.js 변환
tools/build-answers.py ppt-answers.md → answers-data.js 변환
tools/make-icons.py    아이콘 생성
```
